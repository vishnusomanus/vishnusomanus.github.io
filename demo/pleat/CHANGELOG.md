# Changelog

## [Unreleased]

## [1.0.5] - 2026-11-05

### Changed

- Set in Alexandria, Virginia, with American spelling, US dollars, US phone numbers and local details.
- The fitting calendar now closes on US federal holidays, worked out by rule for any year, and uses Eastern time with a 12-hour clock.

## [1.0.4] - 2026-11-05

### Changed

- The guide, README and changelog use American spelling. The template itself is unchanged.

## [1.0.3] - 2026-11-04

### Fixed

- A change the browser couldn't save, for example when its storage is full, now stays in place for the visit
  instead of going back to the old value.

## [1.0.2] - 2026-10-23

### Fixed

- The fitting request and inquiry forms no longer finish by preparing an email, saying the request "has not been
  sent" or that "nothing is sent from this page". The fitting request now confirms the request was received, shows
  a summary and a reference like PL-7K2Q, and promises an email within one working day to confirm the time. The
  inquiry form confirms the inquiry with a reply within two working days and a reference. `DOCS.md` and
  `template.json` describe the new behavior.

## [1.0.1] - 2026-10-19

### Fixed

- The fitting calendar's day buttons and its Earlier and Later buttons now have accessible names that start with their visible text (WCAG 2.5.3).

## [1.0.0] - 2026-10-19

### Added

- Ten complete pages for an independent alterations and repair studio.
- Garment-specific services, a multi-garment estimate and saved repair plan.
- A rolling fitting calendar with specialist availability, England and Wales bank holidays and request review.
- A filterable work ledger, searchable care notes and email inquiry preparation.
- Original drawings for each garment, case study and specialist, an icon for every service, and full documentation.
