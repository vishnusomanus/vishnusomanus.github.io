# Pleat

A complete HTML and Tailwind CSS website for an independent alterations and clothing repair studio in Alexandria, Virginia. Midnight blue, parchment and brass frame original garment, repair and workroom drawings and a practical workroom ledger.

Version 1.0.5 includes nine main pages plus a 404, sixteen detailed services, a multi-garment estimate, saved repair plans, a fitting calendar, work detail dialogs and searchable clothes care notes.

## Quick start

Open `index.html`, or serve this folder with a static server:

```sh
python3 -m http.server 8080
```

Visit `http://localhost:8080`. The compiled CSS, JavaScript and artwork are included; Prata and Kumbh Sans load from Google Fonts. No installation is needed to browse the site.

To change Tailwind utilities, use Node 24, run `npm install`, then `npm run build` from this folder. `npm run watch` rebuilds while you edit.

Read [DOCS.md](DOCS.md) for the data model, estimate calculations, availability rules, backend integration, storage and deployment instructions.
