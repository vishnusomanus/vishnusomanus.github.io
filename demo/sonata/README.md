# Sonata

A complete HTML + Tailwind CSS v4 website for an independent music school. Twelve courses, six teachers, a weekly schedule, a lesson-price calculator and a guided enrollment inquiry, with saved courses and a practice planner.

## Quick start

Open `index.html` directly, or serve this folder with `python3 -m http.server 8080` and open `http://localhost:8080`. The compiled CSS, scripts and artwork are included, and the Lora and Asap fonts load from Google Fonts. No installation is needed to view the site.

To change Tailwind classes, use Node 24, run `npm install`, then `npm run build`.

See [DOCS.md](DOCS.md) for every page, setting, interaction and form connection.
