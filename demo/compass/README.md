# Compass: free HTML5 + Tailwind CSS coaching and consultant website template

A complete website for a leadership coach, built for **Bearing**, the fictional Pittsburgh practice of executive coach
Nadia Whitcombe. It has an editorial design (Source Serif 4 and Instrument Sans on ivory, dusk indigo and marigold),
cut-paper SVG illustrations, a four-step booking flow with a time-zone-aware calendar, a leadership self-check quiz
that recommends a program, filterable client stories with before-and-after numbers, programs with pricing, a
comparison table and FAQ, an interactive method diagram, a resource library and a free-guide sign-up. Plain HTML,
Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.6** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/compass)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
