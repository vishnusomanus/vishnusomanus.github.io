# Tessel — HTML + Tailwind CSS template

A bold, neo-brutalist SaaS website for **Tessel**, a fictional online form and survey builder from Omaha, Nebraska:
a home page with a working mini form builder and live preview, a features page with a conditional-logic demo and
drop-off analytics, a searchable template gallery with previews and a shortlist, pricing with a response-volume
slider, an integrations directory, a changelog, customer stories, a sales form, sign-up and sign-in, and a 404 page.
Plain HTML, Tailwind CSS v4 and vanilla JavaScript, with light and dark themes; every illustration is SVG.

**Version 1.0.0** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/tessel)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
