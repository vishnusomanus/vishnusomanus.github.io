# Matinee: movie theater template

An art deco website for an independent single-screen cinema, made for the fictional **Garnet Theater**, a 1931
movie palace in Missoula, Montana: a marquee home page with tonight's showtimes, a two-week program with a day
list and a week grid filtered by genre and accessibility, a page for every film with its own poster art, seat-map
ticket booking with snacks and a booking reference, memberships with a monthly or annual switch, film series and
private hire, and a visit page with hours, access and the concession menu. Plain HTML, Tailwind CSS v4 and
vanilla JavaScript.

**Version 1.0.4** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/matinee)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
