# Heatloop: free HTML5 + Tailwind CSS tech startup website template

An editorial deep-tech website for a hardware or climate-tech startup, built for the fictional **Heatloop**, a
Bangor, Maine company making a thermal battery that stores cheap off-peak electricity as heat for homes: a product
cutaway and exploded view, an interactive 24-hour charge and electric rate diagram, a savings and carbon estimator with
shareable results, a three-step reservation with a ZIP code check, careers with filters and saved roles, a
company page with a press kit, and news. Plain HTML, Tailwind CSS v4 and one vanilla JavaScript file, with light
and dark themes.

**Version 1.0.3** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/heatloop)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
