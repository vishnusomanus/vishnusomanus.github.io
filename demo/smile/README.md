# Smile: free HTML5 + Tailwind CSS dentist and dental clinic website template

A bright, friendly website for a family and cosmetic dental practice, built for **Grin Lane Dental**, a fictional
practice in Boise, Idaho. Rounded Fredoka and Nunito type, a berry, bubble-pink, lemon and mint palette and Pip the
tooth mascot keep it warm and reassuring. It has a five-step booking flow with real schedule logic, a treatment cost
estimator with membership comparison and a payment-plan calculator, an emergency symptom guide, a multi-step new
patient form, and filterable treatments and team pages. Plain HTML, Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.8** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/smile)

## Quick start

Open `index.html` in a browser. It works right away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```

## Documentation

[DOCS.md](DOCS.md) is the full guide: pages and files, colors and fonts, office hours, clinicians, visit types and

The content is general information for a fictional practice, not medical advice. Review all health copy with a
qualified professional before publishing your own site.
