# Praxlet

A complete HTML5 and Tailwind CSS v4 website for a modular educational robotics company in Nashua, New Hampshire. Nine pages include a sixteen-module catalog, comparison board, kit configurator, six projects and practical field notes.

## Quick start

Open `index.html` in a browser, or serve the folder with `python3 -m http.server 8080`. Compiled CSS and vanilla JavaScript are included. Google Fonts need an internet connection. Node 24 is needed only to rebuild CSS with `npm install` and `npm run build`.

Read [DOCS.md](DOCS.md) for all settings, data, storage keys, forms and deployment instructions.
