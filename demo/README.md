# Freeframe HTML templates

Complete, multi-page website templates in plain HTML and Tailwind CSS, from [Freeframe](https://freeframe.dev/?ref=github).
Every template here is MIT licensed: use it for personal and client projects.

This repository is a read-only copy, updated automatically with each Freeframe release. Previews,
documentation, other stacks and premium templates are on [freeframe.dev](https://freeframe.dev/templates?ref=github).

## Use a template

- **Download one folder:** `npx degit empeeryal/freeframe-templates/<name> my-site`, for example
  `npx degit empeeryal/freeframe-templates/launch my-site`.
- **Or** download it from its page on [freeframe.dev](https://freeframe.dev/templates?ref=github), which also lets you sign up for
  update emails.

Open `index.html` in a browser: no install or build step is needed. Each template's `README.md` and
`DOCS.md` explain how to customize and deploy it.
