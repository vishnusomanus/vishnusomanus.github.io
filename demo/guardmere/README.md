# Guardmere

A nine-page HTML and Tailwind CSS v4 website for an independent cybersecurity practice. Includes a scope calculator, saved readiness checklist, engagement library, field notes and consultation forms.

Open `index.html` in a browser. No installation is needed for the compiled website. Google Fonts require internet access.

Read [DOCS.md](DOCS.md) for customization, data, forms, saved state, dates and deployment.

To rebuild styles with Node 24:

```sh
npm install
npm run build
```
