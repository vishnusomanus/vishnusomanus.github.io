# Hashfen

A complete HTML + Tailwind CSS v4 website for a network research product. Nine pages include twelve network profiles, a transaction assumptions planner, a saved research workspace, pricing and a practical research library.

Open `index.html` in your browser. No installation or build step is needed to use the site. Node 24 and npm are needed only to rebuild CSS after adding new utility classes:

```sh
npm install
npm run build
```

Read [DOCS.md](DOCS.md) for the full customization, data, form integration and deployment guide.
