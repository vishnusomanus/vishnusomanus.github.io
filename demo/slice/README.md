# Slice: pizzeria and takeout template

A fun, appetizing website for a pizzeria or takeout, made for **Crust Club**, a fictional sourdough
pizzeria with two shops in New Haven. Online ordering with a pizza customizer (sizes, crusts, extras,
half and half), a cart drawer with promo codes, a ZIP code delivery checker, deals and a bundle builder, a
checkout with time slots from the opening hours and an animated order tracker. Plain HTML, Tailwind CSS v4
and one vanilla JavaScript file. Every pizza is drawn in SVG from the menu data, so there are no photos to
replace.

**Version 1.0.6** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/slice)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
