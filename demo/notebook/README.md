# Notebook: developer blog template

A personal technical blog, made for the fictional backend engineer **Imke Vos**: a home page with the
latest posts and featured series, a post layout with highlighted code, copy buttons, heading links and
an outline that follows your reading, an archive by year, tags, series, instant search, projects, an
about and now page and a newsletter sign-up. Plain HTML, Tailwind CSS v4 and a small vanilla
JavaScript file.

**Version 1.0.3** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/notebook)

## Quick start

Open `index.html` in a browser. It works right away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
