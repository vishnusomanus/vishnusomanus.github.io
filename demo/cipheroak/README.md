# Cipheroak

A nine-page HTML5 and Tailwind CSS v4 website for Cipheroak, a self-custody security studio in Santa Fe, New Mexico. It includes a vault-readiness assessment, a multisig signer planner, fourteen illustrated security guides with a reading list, a quote builder, rolling field notes and advisories, and review-call booking in Mountain Time.

## Quick start

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8080` and visit `http://localhost:8080`. Google Fonts need an internet connection. No install or build step is needed to view the site.

To rebuild the CSS after changing classes (Node 24):

```sh
npm install
npm run build
```

See [DOCS.md](DOCS.md) for the data structures, saved-state keys, demo-date switches, form integration and deployment.
