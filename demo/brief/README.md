# Brief: free HTML5 + Tailwind CSS lawyer and attorney website template

A complete website for a solo lawyer or independent attorney, built for **Pennington Employment Law**, the fictional Dayton, Ohio, practice of employment attorney Tessa Pennington. It has a calm, modern design
(Literata and Albert Sans on paper, forest ink and a highlighter accent), SVG illustrations, services with
fixed fees, a fee estimator, a branching "what are my options?" check with a claim deadline calculator,
searchable guides, a long-form article and a four-step consultation booking flow. Plain HTML, Tailwind CSS
v4 and one vanilla JavaScript file.

**Version 1.0.8** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/brief)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```

## Documentation

[DOCS.md](DOCS.md) is the full guide: pages and files, colors and fonts, editing matters and fees, the
options check and deadline rules, the booking availability, connecting the forms and a real booking tool,
saved data, SEO, accessibility, deploying and troubleshooting. Changes are listed in
[CHANGELOG.md](CHANGELOG.md).

The sample content is general information about employment law in Ohio and under federal law, written for a
fictional practice. Have a qualified lawyer review all legal wording, fees and regulatory details before
you publish.
