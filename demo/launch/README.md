# Launch — SaaS website template

A complete, multi-page website for a software product, built with HTML5 and Tailwind CSS v4: home,
features, pricing (monthly/annual switch, comparison table, FAQ), about, contact, sign in / sign up and a
404 page, in light and dark themes.

**Version 1.1.8** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/launch)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
