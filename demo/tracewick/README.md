# Tracewick

A nine-page HTML5 and Tailwind CSS v4 observability website, version 1.0.2.

Open `index.html` in a browser. Compiled CSS and dependency-free JavaScript are included. The selected Rajdhani and Golos Text fonts load from Google Fonts.

The service console includes fourteen services, a saved watchlist, alert budgets and a trace query workbench. Other pages cover the platform, usage pricing, engineering guides, reliability, company and contact.

Read [DOCS.md](DOCS.md) for content, styling, saved data, form integration and deployment.

## Rebuild CSS

Use Node 24 and run:

```sh
npm install
npm run build
```
