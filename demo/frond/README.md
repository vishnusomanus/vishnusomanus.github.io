# Frond

A bright, characterful houseplant shop on East 5th Avenue in Eugene, Oregon. Nine pages plus a 404, built with HTML,
Tailwind CSS v4 and dependency-free JavaScript.

## Quick start

Open `index.html`, or serve the folder:

```sh
python3 -m http.server 8080
```

Visit `http://localhost:8080`. No build is needed. To change Tailwind utilities, use Node 24, run `npm install` and
then `npm run build`.

Fifteen illustrated plants with real care notes, search and filters, sizes and cover pots, a saved cart, a
three-step checkout with gift wrap, a card step and an order confirmation with a ship date worked out from the cutoff and US federal holidays, a ranked plant finder, care tools and a visit page with a map and live opening hours.

Read [DOCS.md](DOCS.md) for the data, settings, interactions, forms and launch steps.
