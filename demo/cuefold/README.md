# Cuefold

A complete HTML + Tailwind CSS v4 website for an independent theater in Staunton, Virginia.
Ten pages include a six-week program that stays current, detailed productions, saved
visit planning, access preferences, and ticket and workshop requests.

## Quick start

Open `index.html` in a browser, or serve the folder with any static web server.
The compiled CSS, JavaScript and artwork are included; fonts load from Google Fonts. Nothing needs installing.

To change utility classes, use Node 24, run `npm install` and then `npm run build`.

Read [DOCS.md](DOCS.md) for page details, data, date rules, forms, storage and deployment.
