# Estate: real-estate agency template

A complete website for a real-estate agency, made for the fictional **Harbor & Hill Realty**:
searchable listings, property pages with a gallery and mortgage calculator, saved homes, agent profiles
and valuation requests. Plain HTML, Tailwind CSS v4 and a small vanilla JavaScript file.

**Version 1.1.14** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/estate)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
