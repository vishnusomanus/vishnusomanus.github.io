# Summit: conference and event template

A vibrant website for a conference or event, made for the fictional **Summit 2027**: a live countdown,
speakers with pop-up profiles, a three-day schedule with tracks and "My schedule", tickets with a team
discount, venue and sponsors. Plain HTML, Tailwind CSS v4 and vanilla JavaScript.

**Version 1.1.12** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/summit)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
