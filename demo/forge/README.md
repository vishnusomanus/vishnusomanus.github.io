# Forge — HTML + Tailwind CSS template

A dark, developer-first website for **Forge**, a fictional webhooks API: a home page with a code sample that types
itself in four languages and an interactive API explorer, a quickstart with synced language tabs and copy buttons,
a filterable SDK directory, usage-based pricing with a volume calculator, a filterable changelog, a status page with
90-day uptime bars, a company and careers page, a sales form, an API key sign-up demo and a 404 page. Plain HTML,
Tailwind CSS v4 and vanilla JavaScript; every diagram and illustration is SVG or CSS.

**Version 1.0.6** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/forge)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
