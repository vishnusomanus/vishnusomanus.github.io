01/ Versioning

Upgrades you can plan for.

  1. Dated API versions

    Each key is pinned to an API version such as 2026-09-01. Breaking changes ship as a new date; your integration never changes underneath you.

  2. Semantic SDK releases

    SDK major versions follow API versions. Minor and patch releases are always safe to take, and every release is in the changelog.

  3. 24 months of support

    Old API versions keep working for at least two years after a new one ships, with deprecation warnings in response headers well before.
