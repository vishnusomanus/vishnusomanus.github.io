# Echo: free HTML5 + Tailwind CSS podcast website template

A complete website for an interview podcast, built for the fictional **Overtone**, an independent show about
how things get made, hosted by a designer and a science journalist in Philadelphia: a home page with the
latest episode, an episode archive with filters, episode pages with chapters, show notes and a searchable
transcript, an accessible audio player with a mini player that follows you across pages, hosts, subscribe,
advertise and be-a-guest pages. Plain HTML, Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.6** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/echo)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
