# Northstar Admin — Dashboard template

A complete admin dashboard built with HTML5, Tailwind CSS v4 and vanilla JavaScript: overview, analytics,
orders, customers, products, settings, sign-in and a 404 page, in light and dark themes. No frameworks and
no chart libraries: every chart is SVG drawn by `assets/js/main.js`.

**Version 1.1.12** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/dashboard)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
