# Atlas: free HTML5 + Tailwind CSS real estate agent website template

A complete personal-brand website for an independent real estate agent, built for **Delia Quintero**, a fictional
Nashville agent who trained as an architect. It has a bold, magazine-style design (Gloock and Albert Sans on paper,
cobalt, persimmon and butter), SVG-illustrated property cards, filterable active and sold listings with shareable
URLs, listing pages with an illustrated gallery and open houses you can add to a calendar, a home value estimate, a
seller net proceeds sheet, a buyer affordability calculator, an interactive neighborhood map and a consultation
booking flow. Plain HTML, Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.4** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/atlas)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
