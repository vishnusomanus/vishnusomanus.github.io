# Prism — HTML + Tailwind CSS template

A dark-first website for **Prism**, a fictional AI research assistant with an API: a home page with an
interactive playground that streams cited answers, a product deep-dive with integrations, security and model
stats, pricing with a monthly/annual switch and a usage cost calculator, API docs with code tabs and copy
buttons, a filterable changelog, a company and careers page, a talk-to-sales form and a 404 page. Plain HTML,
Tailwind CSS v4 and vanilla JavaScript; every illustration is SVG or CSS.

**Version 1.0.6** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/prism)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
