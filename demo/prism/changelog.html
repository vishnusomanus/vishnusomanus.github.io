Changelog

What we shipped.

New models, API changes, connectors, security updates and fixes, newest first. Get them by email.

October 8, 2026

v2.0

Prism 2 is generally available

  • Models
  • Product

Our new default model writes 41% fewer unsupported claims than Prism 1.5 on SourceQA-Hard, reads up to 1M tokens in one pass and starts answering in a median 380 ms.

  • prism-2 replaces prism-1.5 as the default in the app and the API.
  • Claims without a supporting passage are now underlined in drafts, with the reason.
  • prism-1.5 keeps working until April 30, 2027.
September 24, 2026

v1.18

Sources stream before the answer

  • API

Streaming responses now send a source event for each passage before the first text event, so you can render citations as soon as they exist.

  • New source event type with index, title and quote.
  • The final done event includes unsupported_claims.
September 10, 2026

v1.17

Data warehouse connector

  • Connectors

Connect a warehouse with a read-only role and ask questions in plain language. Prism writes the SQL, shows it to you and cites the result table.

  • Supports schemas up to 2,000 tables.
  • Queries time out after 60 seconds and never write.
August 27, 2026

v1.16

SCIM provisioning and audit log export

  • Security

Enterprise workspaces can now provision and remove users from their identity provider, and stream the audit log to their own storage.

  • SCIM 2.0 for users and groups (beta).
  • Daily audit log export as JSON Lines.
August 13, 2026

v1.15

Briefs can post to webhooks

  • Product
  • API

Scheduled briefs can now send their result to any HTTPS endpoint, signed with your workspace secret.

  • Payloads include the answer, citations and what changed since the last run.
  • Retries for up to 24 hours with exponential backoff.
July 30, 2026

v1.14.2

Fixes for pagination and long PDFs

  • Fixes
  • API

A round of fixes reported by API customers.

  • /v1/search cursors no longer skip results when documents change mid-page.
  • Citation offsets are correct in scanned PDFs over 500 pages.
  • The Python SDK no longer drops the last event of a stream on slow connections.
July 16, 2026

v1.14

prism-2-flash gets 40% faster

  • Models

A new serving stack cuts median time to first token for prism-2-flash from 230 ms to 140 ms, with no change in price.

July 2, 2026

v1.13

Usage endpoint and spending caps

  • API

See token usage per key and per day, and set a hard monthly cap on any key.

  • New GET /v1/usage endpoint.
  • Requests over a cap return 402 with cap_reached.
June 18, 2026

v1.12

Calendar and meeting notes

  • Connectors
  • Product

Prism can now read your calendar and the notes attached to meetings, so “what did we agree with Arcwell?” has an answer.

June 4, 2026

v1.11

Choose your US data region

  • Security

Choose where your index, chat history and logs are stored: US East (Virginia), US Central (Iowa) or US West (Oregon). Existing workspaces can migrate from the admin panel.

May 21, 2026

v1.10.1

Fixes for the editor and briefs

  • Fixes

Smaller fixes across the app.

  • Citations no longer disappear when you undo an edit.
  • Briefs scheduled for the last day of the month run on shorter months.
