Quickstart

Your first answer in three steps.

  1. 1

    Create a key

    In the dashboard, open Settings → API keys. Free workspaces get test keys with 100k tokens a month. Keep keys on the server.

    Terminal

    export PRISM_API_KEY="pk_test_your_key_here"
  2. 2

    Ask a question

    Point sources at your workspace, the web or both. Every answer comes back with citations and quotes.

    curl https://api.prism.example/v1/answers \
  -H "Authorization: Bearer $PRISM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "prism-2",
    "question": "What changed in our refund policy this year?",
    "sources": ["workspace", "web"]
  }'
    import Prism from "@prismlabs/sdk";

const prism = new Prism({ apiKey: process.env.PRISM_API_KEY });

const answer = await prism.answers.create({
  model: "prism-2",
  question: "What changed in our refund policy this year?",
  sources: ["workspace", "web"],
});

console.log(answer.text);
for (const c of answer.citations) console.log(c.index, c.title);
    from prismlabs import Prism

client = Prism()  # reads PRISM_API_KEY from the environment

answer = client.answers.create(
    model="prism-2",
    question="What changed in our refund policy this year?",
    sources=["workspace", "web"],
)

print(answer.text)
for c in answer.citations:
    print(c.index, c.title)
  3. 3

    Stream it

    Set "stream": true to receive server-sent events: source, text and a final done with usage.

    curl -N https://api.prism.example/v1/answers \
  -H "Authorization: Bearer $PRISM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "prism-2-flash", "question": "Summarize this week in support", "stream": true}'
    const stream = await prism.answers.stream({
  model: "prism-2-flash",
  question: "Summarize this week in support",
});

for await (const event of stream) {
  if (event.type === "text") process.stdout.write(event.text);
}
    with client.answers.stream(
    model="prism-2-flash",
    question="Summarize this week in support",
) as stream:
    for event in stream:
        if event.type == "text":
            print(event.text, end="")

Reference

Endpoints

Base URL https://api.prism.example. JSON in, JSON out, versioned in the path. Breaking changes get a new version and twelve months of overlap.

  • POST/v1/answersAsk a question, get a cited answer
  • POST/v1/searchRanked passages, no generation
  • POST/v1/documentsAdd or update a document in your index
  • GET/v1/documents/{id}A document and its sync status
  • DELETE/v1/documents/{id}Remove a document from the index
  • POST/v1/briefsSchedule a recurring question
  • POST/v1/embeddingsVectors from prism-embed-1
  • GET/v1/usageToken usage by key and day

SDKs

Official libraries, typed and tested.

Retries with backoff, streaming helpers and pagination built in. Open source under the MIT license.

  • JavaScriptv3.2

    Node 20+, Deno, Bun and edge runtimes. Full TypeScript types.

    npm i @prismlabs/sdk

  • Pythonv3.1

    Python 3.9+, sync and async clients, Pydantic models.

    pip install prismlabs

  • Gov1.4

    Context-aware, zero dependencies beyond the standard library.

    go get prism.example/go

  • RubyBeta

    Ruby 3.2+, with a Rails generator for webhooks.

    gem install prismlabs
