# Market — HTML + Tailwind CSS template

A complete online store for **Kiln & Co.**, a fictional handmade-ceramics studio: home, a filterable shop,
product pages with variants, a cart saved in the browser, a slide-out mini cart, a validated demo checkout,
about, FAQ with contact form and a 404 page. Product images are drawn in SVG, so there are no photos to
replace. Plain HTML, Tailwind CSS v4 and vanilla JavaScript.

**Version 1.1.11** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/market)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
