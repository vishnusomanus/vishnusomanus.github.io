# Orbit — HTML + Tailwind CSS template

A bright, product-led SaaS website for **Orbit**, a fictional shift-scheduling app for restaurants, cafés,
hotels and shops: a home page with a live drag-and-drop schedule demo, feature deep-dives with a comparison
against spreadsheets and group chats, pricing with a per-location and per-employee calculator, a searchable
integrations directory, filterable customer stories, a changelog, an about and careers page, a sales form that
routes by team size, a three-step free trial sign-up and a 404 page. Plain HTML, Tailwind CSS v4 and vanilla
JavaScript; every illustration is SVG or CSS.

**Version 1.0.6** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/orbit)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
