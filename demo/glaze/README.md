# Glaze — HTML + Tailwind CSS template

A shop website for **Vennick Clay**, a fictional pottery studio on Mesquite Street in Las Cruces, New Mexico: a home
page with a still life drawn in SVG, a shop of twelve stoneware pieces filtered by shape, glaze and “ready to
ship”, product pages with glaze and size choices, stock and delivery dates, workshop booking with dates that
roll forward, a saved cart with shipping or free pickup, a checkout with an order confirmation, the
studio story and glaze guide, care and shipping, a visit page with live opening hours and kiln-opening
Saturdays, and a 404 page. Every pot is drawn from the product data, so there are no photos to replace. Plain
HTML, Tailwind CSS v4 and vanilla JavaScript.

**Version 1.0.5** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/glaze)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
