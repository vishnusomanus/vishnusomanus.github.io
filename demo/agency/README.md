# Agency: free HTML5 + Tailwind CSS template

A complete website for a creative or digital agency, built for the fictional **Northbound Studio**:
home, services, filterable work, a full case study with a before/after slider, about, careers with an
application form, a project-brief contact form and a 404 page. Plain HTML, Tailwind CSS v4 and a small
vanilla JavaScript file.

**Version 1.1.9** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/agency)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
