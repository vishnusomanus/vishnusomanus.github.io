# Fitness: gym and fitness studio template

A bold, dark website for a gym or fitness studio, made for the fictional **Keel Athletic Club** in New Bedford, Massachusetts: a
weekly schedule with class booking, class and coach profiles, membership pricing with a BMI and
calorie calculator, and a free-trial sign-up. Plain HTML, Tailwind CSS v4 and a small vanilla JavaScript
file.

**Version 1.1.13** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/fitness)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
