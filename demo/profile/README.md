# Profile: personal website template

A developer portfolio for the fictional engineer **Sam Lindqvist**: a printable résumé, filterable
projects, a writing archive, a /uses page and a contact form, with a ⌘K command palette and dark mode.
Plain HTML, Tailwind CSS v4 and a small vanilla JavaScript file.

**Version 1.1.12** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/profile)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
