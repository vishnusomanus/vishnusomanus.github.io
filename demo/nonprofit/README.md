# Nonprofit: charity template

A warm, trustworthy website for a charity, made for the fictional clean-water charity **Clearwater
Trust**: impact counters, an appeal progress bar, programs with a region map, field stories,
volunteering, events and a full donate page. Plain HTML, Tailwind CSS v4 and a small vanilla JavaScript
file.

**Version 1.1.9** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/nonprofit)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
