# Petal — HTML + Tailwind CSS template

A shop website for **Hollyhock**, a fictional independent florist on Mulberry Street in Macon, Georgia: a seasonal home
page with a live “order by 1pm for same-day delivery” countdown, a shop filtered by occasion, color and price,
product pages with sizes, a delivery calendar and a gift message, a saved cart with a ZIP code check, a demo
checkout, a flower subscription builder, weddings and events with an estimate, a flower care guide, about and
contact, and a 404 page. Every bouquet is drawn in SVG from the product data, so there are no photos to
replace. Plain HTML, Tailwind CSS v4 and vanilla JavaScript.

**Version 1.0.6** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/petal)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
