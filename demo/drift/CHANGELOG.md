# Changelog

All notable changes to the Drift template are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this template follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.5] - 2026-11-05

### Changed

- Set in Sacramento, California, with American spelling, US dollars, and local details.
- Times now show on a 12-hour clock, in the calculator and routine builder too; saved settings and `?time=` links still use 24-hour `HH:MM`.

## [1.0.4] - 2026-11-05

### Changed

- The guide, README and changelog use American spelling. The template itself is unchanged.

## [1.0.3] - 2026-11-04

### Fixed

- A change you make is kept for the visit when the browser can't save it, for example when its storage is full, instead of going back to the old value.

## [1.0.2] - 2026-10-23

### Fixed

- The support contact form's thank-you message no longer says it is a demo that didn't send anything. It now
  confirms the message is with the support team, promises a reply within one working day (as the page already
  says) and shows a reference like NJ-7K2Q. `DOCS.md` describes the reference.

## [1.0.1] - 2026-10-19

### Fixed

- The press kit's copy-color buttons' accessible names now include their visible text (WCAG 2.5.3).

## [1.0.0] - 2026-10-17

### Added

- Nine pages: home, features, sound library, bedtime calculator, pricing, reviews, sleep guides, support and press kit, and 404.
- Dark-first night sky design with SVG star fields, moon artwork, aurora gradients and a light ("dawn") theme toggle.
- Phone mockups with five app screens (tonight, sounds, smart alarm, wind-down, sleep diary) built in HTML and SVG.
- Tabbed feature tour on the home page that swaps the phone screen, with arrow-key support.
- Bedtime calculator with wake-up and bedtime modes, a fall-asleep allowance, shareable links and saved settings.
- Sound library with category filters, search, saved favorites and 30-second Web Audio previews.
- Wind-down routine builder that works out when to start and remembers your steps.
- Pricing with a monthly / annual switch, comparison table and FAQ.
- Reviews with rating and topic filters and sorting; sleep guides with a topic filter.
- Searchable help center, validated contact form, press kit with copy buttons and a privacy summary.
- Scroll reveals, a back-to-top button and reduced-motion support.
