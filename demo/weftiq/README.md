# Weftiq

A nine-page HTML5 and Tailwind CSS v4 website for a workflow automation company in Plano, Texas. Includes a recipe library, a working rule-and-action builder, saved flows, pricing, integrations and original SVG artwork.

## Quick start

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8080`. Google Fonts need an internet connection. No install or build is needed to view the site.

To rebuild CSS with Node 24:

```sh
npm install
npm run build
```

See [DOCS.md](DOCS.md) for data, saved-state keys, form integration and deployment instructions.
