# Loftwing

A nine-page HTML5 and Tailwind CSS v4 pre-launch website for Loftwing, an email marketing startup in Spokane,
Washington. Every page drives to one waitlist. Includes a live launch countdown, a working subject-line tester, a
five-tab product tour, a waitlist flow with a queue position and referral tiers, a founding-member pricing
calculator, a migration estimator, a votable roadmap, a filterable build journal and a contact form.

## Quick start

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8080`. Google Fonts need an
internet connection. No install or build is needed to view the site.

To rebuild the CSS after changing Tailwind classes (Node 24):

```sh
npm install
npm run build
```

See [DOCS.md](DOCS.md) for the content data, features, saved-state keys, date rules, form integration and
deployment.
