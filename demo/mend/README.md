# Mend: physical therapy clinic website template

A calm, clinical-but-warm website for an independent physical therapy and sports injury clinic, made for the
fictional **Ledgerock Physical Therapy** in Billings, Montana, and laid out like a clinician's notepad. It
opens with a "Where does it hurt?" body map that leads into a four-step online booking with health
screening, and has treatments with prices, conditions from neck to heel, a home exercise library with a
saved plan and rep counter, clinician profiles, prices and insurance, and contact. Plain HTML, Tailwind
CSS v4 and one vanilla JavaScript file.

**Version 1.1.4** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/mend)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
