# Canopy: free HTML5 + Tailwind CSS campground website template

A northwoods campground and cabins website, built for the fictional **Tamarack Pines Campground & Cabins**, a
family-run campground on Lake Superior near Marquette, Michigan: a season status that is always up to date, an
interactive SVG map of 25 sites and cabins with filters, a booking calendar with seasonal and weekend rates and
add-ons, trails with elevation profiles, guided programs, and a camp store pre-order basket. Plain HTML, Tailwind
CSS v4 and one vanilla JavaScript file, drawn in a trail-map style.

**Version 1.0.4** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/canopy)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
