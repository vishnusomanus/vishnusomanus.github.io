# Cogmere

A complete bicycle repair workshop website in HTML and Tailwind CSS v4. Ten responsive pages, original illustrations, a multi-job repair estimator, a rolling drop-off booking and a saved pre-ride checklist.

## Quick start

Open `index.html` in a browser. The compiled stylesheet is included and the fonts load from Google Fonts; no install is needed.

To add new Tailwind classes, use Node 24, run `npm install`, then `npm run build`. Use `npm run watch` while editing.

Read [DOCS.md](DOCS.md) for the page map, data, date rules, saved state, forms, accessibility and deployment instructions.
