# Rillmark: free HTML5 + Tailwind CSS motion designer portfolio template

A complete portfolio website for an independent motion designer and director, built for **Rillmark**, the
fictional Hartford studio of Marika Drever: title sequences, brand motion, explainer animation and music
videos. It is editorial and kinetic: a variable-width display face that stretches into place, monospace
slates and timecodes, a cool lilac paper and deep plum night sections. Every frame of artwork is SVG,
drawn from the project data. Plain HTML, Tailwind CSS v4 and vanilla JavaScript.

The home page plays a showreel drawn live from six projects, with play/pause and scene controls that
respect reduced motion. The work index filters fifteen projects by discipline and year, with search and a
saved shortlist; every project has its own case study with a styleframe scrubber. The services page
estimates a fee with a full breakdown in dollars, the journal and availability roll forward with the
calendar, and the inquiry form finishes with a reference and next steps.

**Version 1.0.3** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/rillmark)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
