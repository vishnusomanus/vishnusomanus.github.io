# Bistro: restaurant template

A warm, high-end website for a restaurant, café or wine bar, made for the fictional **Olive & Ember**:
tabbed menus with dietary filters, reservations whose time slots follow the opening hours, private
dining, a live "open now" badge and contact. Plain HTML, Tailwind CSS v4 and a small vanilla JavaScript
file.

**Version 1.1.11** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/bistro)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
