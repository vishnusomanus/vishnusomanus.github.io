# Soiree: wedding and event planner website template

An editorial, magazine-style website for a fictional wedding and event planning studio, Ivy & Ash Events in
Charleston, South Carolina: service packages with a comparison table, a budget estimator, a filterable portfolio
with case studies, a planning timeline, a venue guide with a saved shortlist, a journal and a validated inquiry
form. Built with HTML5, Tailwind CSS v4 and vanilla JavaScript.

**Version 1.0.5** · see [CHANGELOG.md](CHANGELOG.md) for what changed.

Live demo: [freeframe.dev/templates/soiree](https://freeframe.dev/templates/soiree)

## Quick start

Open `index.html` in a browser: no install or build step is needed. To preview it as a host serves it:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

Node.js 24 is only needed to rebuild the CSS (`npm install`, then `npm run build`).
