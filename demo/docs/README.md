# Manual: documentation template

A developer documentation site for **Relay**, a fictional JavaScript HTTP client: docs home, quick
start, installation, guides, examples, API reference, changelog and FAQ, with ⌘K search, code tabs and
dark mode. Plain HTML, Tailwind CSS v4 and a single vanilla JavaScript file.

**Version 1.1.11** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/docs)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
