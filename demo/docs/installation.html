Installation

Relay ships as an ES module with TypeScript types included. It works anywhere the standard fetch API exists.

#Package managers

Pick your package manager. Your choice is remembered across every page of these docs.

npm install @relayhttp/relay
pnpm add @relayhttp/relay
yarn add @relayhttp/relay
bun add @relayhttp/relay

#Requirements

#Without a bundler

Load the module build straight from a CDN with a module script. This is handy for prototypes and plain HTML pages.

index.html
<script type="module">
  import relay from 'https://cdn.example.com/@relayhttp/relay@3.2.0/dist/relay.min.js';

  const status = await relay.get('/api/status').json();
  document.querySelector('#status').textContent = status.message;
</script>

Pin the version

Always include an exact version in CDN URLs. Unpinned URLs can pick up a new major version and break your page without warning.

#TypeScript

Types are bundled, so there's nothing extra to install. Pass a type parameter to .json() to type the response body:

user.ts
interface User {
  id: number;
  name: string;
  email: string;
}

const user = await relay.get('users/42').json<User>();
user.email; // string

#Deno

main.ts
import relay from 'npm:@relayhttp/relay@3';

const { version } = await relay.get('https://api.example.com/version').json();

#Verify the install

Run this one-liner to check that Relay loads and can reach the network:

Terminal
node -e "import('@relayhttp/relay').then(m => m.default.get('https://httpbin.org/get').json()).then(r => console.log('ok', r.url))"
