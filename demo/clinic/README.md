# Clinic: dental and medical practice template

A calm, accessible website for a dental or medical practice, made for the fictional **Brightside
Dental**: treatments and costs, the care team, patient information and a five-step online booking
wizard. Plain HTML, Tailwind CSS v4 and a small vanilla JavaScript file.

**Version 1.1.12** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/clinic)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
