# Sprout: HTML5 + Tailwind CSS gardening school and course website template

A field-notebook website for a practical gardening school, built for the fictional **Loamstead field school** in
Corvallis, Oregon: ten courses with their own pages and drawings, a filterable course list, an upcoming-sessions
schedule with places left, a three-step enrollment request, a bed planner that draws your plants to scale, a saved
shortlist, instructor profiles, and real accessibility, booking and student safety copy. Course dates are worked out from rules, so
the demo never goes stale. Plain HTML, Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.5** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/sprout)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
