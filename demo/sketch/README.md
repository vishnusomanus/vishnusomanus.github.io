# Sketch — HTML + Tailwind CSS template

A website for **Marnie Draws**, the fictional personal brand of Marnie Ashdown, an illustrator in Asbury
Park, New Jersey, who teaches drawing on the iPad: a home page with her flagship course and a student work wall, a course
catalog with level and topic filters and saved courses, a course sales page with a computed curriculum
and an early-bird countdown, live workshops in Eastern time with seats left and a waitlist, free downloadable
worksheets and palettes, a student gallery with a lightbox, about, newsletter, contact and a 404 page.
Every illustration is SVG, so there are no photos to replace. Plain HTML, Tailwind CSS v4 and vanilla
JavaScript.

**Version 1.0.6** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/sketch)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
