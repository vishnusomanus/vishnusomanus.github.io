# Wardline

A ten-page HTML5 and Tailwind CSS v4 website for Wardline, a compliance automation company in Richmond, Virginia.
Includes a hero control dashboard, a six-tab platform tour with product mockups, a framework explorer with
SOC 2, ISO 27001, HIPAA, GDPR, PCI DSS and NIST CSF cross-mapping, a readiness assessment, a pricing calculator,
an integrations directory, a trust center with a document request flow, customer stories and a three-step demo
booking in the visitor's time zone.

## Quick start

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8080`. Google Fonts need an
internet connection. No install or build is needed to view the site.

To rebuild the CSS after changing Tailwind classes (Node 24):

```sh
npm install
npm run build
```

See [DOCS.md](DOCS.md) for the content data, features, saved-state keys, date rules, form integration and
deployment.
