# Solace: therapy and counseling practice website template

A calm, warm website for a therapy practice, made for the fictional **Budd Bay Counseling**, a group practice
in Olympia, Washington: a therapist match quiz, a filterable clinician directory with profiles, fees with a
sliding-scale calculator and insurance checker, therapy groups, a searchable FAQ and a three-step consultation
request, with a crisis panel on every page. Plain HTML, Tailwind CSS v4 and vanilla JavaScript.

**Version 1.0.3** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/solace)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
