# Paws: veterinary clinic website template

A warm, friendly website for an independent vet clinic, made for the fictional **Sweetgum Animal
Clinic** in West Asheville, North Carolina: services filtered by pet, a four-step appointment request
with saved pets, a vaccine and wellness planner, a pricing estimator, team, new-client info and pet care
articles. Plain HTML, Tailwind CSS v4 and a small vanilla JavaScript file.

**Version 1.0.4** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/paws)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
