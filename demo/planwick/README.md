# Planwick

A spacious product-planning SaaS website in HTML and Tailwind CSS v4. Nine pages include a roadmap workspace, priority scoring, release capacity, seat pricing, connection rollout and planning library.

## Quick start

Open `index.html`. Compiled CSS is included; fonts load from Google Fonts. No installation is needed.

To add Tailwind classes, use Node 24, run `npm install`, then `npm run build`. Use `npm run watch` while editing.

Read [DOCS.md](DOCS.md) for pages, content, saved data, date rules, forms and deployment.
