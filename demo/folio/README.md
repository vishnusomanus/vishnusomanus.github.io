# Folio: portfolio template

A dark, type-led portfolio for product designers, developers and small studios, made for the fictional
designer **Mira Okafor**: home, filterable work, a full case study, about, contact with a project
inquiry form and a 404 page. Plain HTML, Tailwind CSS v4 and a small vanilla JavaScript file.

**Version 1.1.10** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/folio)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
